# SocratesBot v0.2 頁面功能規格書

文件日期：2026 年 11 月 3 日

修訂日期：2026 年 11 月 5 日

適用版本：問導魷 SocratesBot v0.2 prototype

本文件依目前原型整理 17 個頁面的功能，逐一說明使用者如何進入、頁面顯示什麼、可以輸入哪些欄位、點擊按鈕後的結果，以及不同身分的操作權限。各頁的頁籤、浮動視窗、提示與使用者故事也一併列出。頁面中的「探究」「主題」「活動」均指課程內的一次 AI 對話活動；本文件統稱「活動」。

核心流程為教師整理並確認八欄設定、學生進行獨立對話、系統產生個人報告，再依報告整理全班觀點，由教師審閱後發布。現行版本為 prototype；AI 內容、語音轉文字、用量與金額等以示範資料呈現。

## 閱讀方式與頁面索引

本文件列的是目標功能及目前原型的完成情形。現有原型可用來確認畫面與操作；真實課堂的多位使用者、跨裝置資料同步與正式使用結果尚未完整驗證。未驗證的項目不標成正式完成。

- **原型可操作**：已有可操作的欄位、按鈕及畫面流程，使用示範資料；不代表正式版本已驗收完成。
- **僅示範**：目前只有預置內容、模擬生成或假金額；真實結果仍是未完成目標。
- **部分完成**：同一頁已有可操作功能，也包含僅示範或尚未製作的目標。
- **尚未製作**：已確認的目標還沒有可用畫面或操作。
- **待驗證／待確認**：完成結果尚未驗證，或目標、規則仍需確認，不推定已完成。

## 共用介面與帳號操作

### Header

目前狀態：原型可操作。角色導覽、本人姓名、頭像選單與語言切換已有介面；部分翻譯仍未完成。

- **LOGO**：顯示「問導魷 SOCRATIC CLASSROOM」。訪客點擊回公開首頁；已登入者點擊回其身分的首頁。
- **未登入**：提供登入、註冊入口。
- **學生與教學端**：直接顯示「我的課程」文字入口，窄螢幕不改成三條線。進入課程後，課名放在內容標題，不再加入 Header；課程代碼也放在課程內容區。
- **管理員**：顯示「管理帳號」，進入老師帳號管理。
- **助教**：可使用教學端課程，也可切換到自己的學生課程；較窄版面可由帳號選單切換。
- **介面語言**：提供繁體中文、English、Español。介面語言與活動內容語言分開；目前部分固定文案仍未翻譯，不代表完整三語支援已完成。
- **帳號選單**：以本人姓名及身分顯示。學生與老師登入後，點擊右上角頭像展開選單，可選擇「修改密碼」或「登出」。老師另有 AI 用量與金鑰入口；助教另有學生課程入口。
- **登出**：清除目前登入狀態，返回公開入口。無側邊導覽列。

### 學生姓名與匿名顯示

目前狀態：原型可操作。學生看同學匿名、老師與獲授權助教看真名，已在現有示範畫面區分。

| 查看者 | 看見其他學生的方式 |
| --- | --- |
| 學生 | 只能看見匿名資訊，不顯示同學真名、帳號或身分對照 |
| 老師 | 在自己課程的學生名單、觀點分類與學生報告中，看見學生真名 |
| 助教 | 在老師授權查看的學生名單、觀點分類與學生報告中，看見學生真名 |

真名採用註冊時填寫的「姓名」。學生之間匿名，不會隱藏老師及獲授權助教可查看的姓名。助教的查看範圍仍由老師勾選權限決定；檢視名單與檢視報告分別授權。

學生本人的頭像選單仍顯示自己的姓名；匿名規則針對查看其他學生的資訊。學生沒有公開同學真名或切換同學匿名狀態的操作。

### Footer

目前狀態：部分完成。隱私權、版權、開發者、聯絡我們與 Bug 文字已顯示，點擊後的內容與回報功能尚未製作。

- **未完成目標**：隱私權、版權、開發者、聯絡我們的內容及可閱讀入口。
- **Bug 回報目標**：點擊 Bug 開啟浮動視窗，填寫問題標題、問題內容並按回報送出。目前只有文字，視窗、輸入欄位及送出操作均尚未製作。

### 修改密碼視窗

目前狀態：原型可操作。學生及老師可從頭像開啟三欄表單，顯示驗證錯誤並示範成功與取消；真實帳號的修改結果尚未完整驗證。

學生與老師可在已登入頁面點擊右上角頭像，再選擇「修改密碼」，開啟與老師首次登入共用的三欄浮動視窗。助教與管理員亦保留此入口。

| 欄位或操作 | 行為 |
| --- | --- |
| 原密碼 | 必填，以密碼欄位輸入 |
| 新密碼 | 8 至 128 字元，不得與原密碼相同 |
| 確認新密碼 | 必須與新密碼一致 |
| 修改密碼 | 驗證後送出；處理中停用重複操作，成功後關閉視窗、停留原頁並維持登入 |
| 取消 | 一般修改可取消，Esc 或點擊外側亦可關閉；重新開啟時清空密碼欄位 |

帳號帶有首次登入必須改密碼狀態時，自動開啟同一視窗，標題為「設定首次登入密碼」。此模式不能以 Esc 或點擊外側略過；離開選項改為登出。舊版「僅初次登入可改密碼」已由頭像選單功能取代。系統沒有電子郵件、忘記密碼信件或自助找回流程。

密碼不符、原密碼錯誤或送出失敗時顯示提示，讓使用者修改後重試。處理中顯示送出狀態並避免重複操作。

使用者故事：作為已登入使用者，我希望從頭像修改自己的密碼；若系統要求初次更換，我必須完成或登出。

## P01 公開首頁

入口：開啟網站，或訪客點擊 Header 的 LOGO。使用者：所有使用者。目前狀態：原型可操作。

**目前具備**：介紹、三階段說明、登入註冊及角色首頁導向已具備；快速體驗使用示範帳號。

**未完成目標與待確認事項**：本頁既定原型畫面沒有已確認的待製作項目；示範帳號不作正式帳號使用。

### 顯示與操作

- 顯示產品介紹、三階段教學流程及一段靜態師生對話範例。範例不是可輸入的聊天室。
- **開始使用入口**：訪客前往登入；已登入者前往對應首頁，包含老師課程、學生課程或管理員管理頁。
- **改動公告**：前往 P02。
- **教師體驗、學生體驗、助教體驗**：示範模式使用指定假帳號登入並前往對應首頁。送出時停用重複點擊，失敗顯示提示。
- 共用 Header 提供登入及註冊。首頁沒有真實 AI 對話或課程建立表單。

使用者故事：作為首次使用者，我希望先了解三階段流程，再選擇登入或註冊。

## P02 改動公告

入口：公開首頁的「改動公告」。使用者：所有使用者。目前狀態：原型可操作。

**目前具備**：預置公告可排序、展開、收合，並有無公告提示。

**未完成目標與待確認事項**：目前目標是閱讀公告，此頁原型已具備。公告管理頁尚未提供，是否納入本版目標待確認。

### 顯示與操作

- 依日期由新至舊顯示公告，包含日期、標題、摘要與可展開內文。
- **展開或收合公告**：在同頁閱讀完整公告，不另開文章頁。
- 無公告時顯示「目前沒有公告」。
- 此頁沒有新增、編輯、刪除公告功能；示範工具加入的臨時公告不構成管理後台。

使用者故事：作為使用者，我希望在使用前查看系統更新及重要通知。

## P03 註冊

入口：Header 的「註冊」或登入頁的註冊入口。使用者：未登入訪客。目前狀態：原型可操作。

**目前具備**：帳號、姓名、兩次密碼、小寫限制、錯誤提示與註冊後進入課程已具備。

**未完成目標與待確認事項**：示範帳號建立流程可操作；使用真實帳號註冊及跨裝置登入的完成度尚未驗證。

### 欄位與操作

| 欄位或操作 | 規則及結果 |
| --- | --- |
| 帳號名稱 | 必填，去除首尾空白後最多 64 字元；英文字母限定小寫，輸入大寫須提示錯誤，不自動改寫 |
| 姓名 | 必填，去除首尾空白後 1 至 128 字元；獨立於登入帳號，供老師辨識學生 |
| 建立密碼 | 必填，至少 8 字元 |
| 確認密碼 | 必須與建立密碼一致 |
| 註冊 | 通過檢查後送出；成功自動登入並前往 P05，並非回登入頁 |
| 已有帳號入口 | 前往 P04 |

小寫限制針對英文字母，不表示帳號只能輸入 a 至 z；現有數字及連字號帳號可用。重複帳號或欄位錯誤須保留其他輸入供修改；處理中停用重複送出。沒有電子郵件、角色選擇或自行註冊老師功能。

使用者故事：作為學生，我希望填寫帳號、姓名與密碼後直接開始使用課程。

## P04 登入

入口：Header 的「登入」或首頁的開始使用入口。使用者：未登入訪客。目前狀態：原型可操作。

**目前具備**：角色導向、登入錯誤提示及首次強制修改密碼視窗已具備。

**未完成目標與待確認事項**：目前可示範登入；真實帳號登入與持續使用的完成度尚未驗證。

### 顯示與操作

- 輸入帳號與密碼；帳號去除首尾空白，含大寫英文字母時顯示小寫限制。
- **登入**：成功後依身分進入 P05、P09 或 P15。一般帳號若有助教指派，可優先進教學端。
- 若原本造訪需登入頁面，登入後可返回通過權限檢查的站內目的頁。
- **註冊入口**：前往 P03。
- 欄位缺漏、帳密錯誤或服務錯誤須顯示提示，登入處理中避免重複送出。
- 首次登入需改密碼時，自動開啟共用強制修改視窗。無忘記密碼、寄信或登入方式切換。

使用者故事：作為使用者，我希望以帳號密碼登入自己的工作或學習頁面。

## P05 學生我的課程

入口：學生登入後的首頁，或 Header 的「我的課程」；助教可切換「學生課程」。使用者：已登入學生；助教可切換至本人學生課程。目前狀態：部分完成。

**目前具備**：課程搜尋、加入、退出、進入課程，以及「頭像 → 修改密碼」均已有原型操作。

**未完成目標與待確認事項**：已確認退出或被移除後仍可查看本人歷史報告；目前退出後沒有對應的歷史檢視入口，尚未完成。老師與學生跨裝置同步仍待驗證。

### 頭像選單與修改密碼

- **點擊頭像**：展開帳號選單，提供「修改密碼」及「登出」。學生其他已登入頁面也可使用此入口。
- **修改密碼**：開啟浮動視窗，輸入原密碼、新密碼及確認新密碼。成功後關閉視窗並停留原頁；取消不變更密碼，錯誤時顯示提示供重試。

### 顯示與操作

- 顯示已加入課程卡片，包含課程名稱、老師姓名、課程代碼及可參與的活動數。
- **搜尋課程**：依課名、課程代碼或老師姓名篩選。
- **加入課程**：開啟浮動視窗，只輸入課程代碼。輸入去除首尾空白並轉大寫；點擊加入後成功關閉視窗、更新列表並顯示提示。
- 代碼不存在、重複加入或服務錯誤時，在視窗保留代碼並顯示原因；取消不加入。
- **課程名稱或進入課程**：前往 P06。
- **退出課程**：先顯示確認視窗；確認後撤銷本人課程資格並更新列表，不刪除老師的課程。目標為保留且可查看本人歷史報告；目前尚需補上退出後的歷史檢視入口。
- 載入失敗可重試；尚未加入任何課程及搜尋無結果須分別顯示空狀態。

使用者故事：作為學生，我希望用課程代碼加入課程，並能在不再參與時退出。

## P06 學生課程活動列表

入口：在學生我的課程點擊課程名稱或「進入課程」。使用者：該課程學生。目前狀態：部分完成。

**目前具備**：已發布活動、本人進度、搜尋、開始／繼續及結果入口已具備。

**未完成目標與待確認事項**：已確認學生放棄後可以重開探究。原型尚需補齊重新開始入口、活動卡狀態及重開後可正常作答的流程，不能標為已完成。

### 顯示與操作

## P13 全班觀點與學生報告

入口：課程管理頁的「檢視觀點」，或發布活動後進入。使用者：課程老師及被指派助教，細項依授權。目前狀態：部分完成。

- 顯示報告待處理、失敗或有新報告尚未納入的提示；不能把可用報告數當作全班完成數。
- **產生觀點摘要／重新整理摘要**：老師或有「編輯全班摘要」權限的助教可用；依現有可用報告產生草稿，不必等全班完成。沒有可用報告時不能產生。

### 摘要審閱頁籤

- 顯示摘要狀態、版本及日期；內容包含全班概述、可用報告分布圖、觀點總結、各群組的標題、說明、人數與比例。
- 觀點依學生實際報告動態歸組，不預設支持、反對等固定結論類別。
- 立場尚未明確或資料不足者另列，不強制分入群組。比例以本次摘要的可用報告為基礎，須明確顯示分母。
- **老師與助教查看學生**：老師及有「檢視學生報告」權限的助教，可在觀點卡及未定清單看見學生真名（註冊姓名）。學生之間的匿名不影響此處顯示，學生也不能自行對老師或獲授權助教隱藏姓名。
- **點擊 Perspective 觀點分類**：具有報告權限時切到學生報告，帶入該群組 tag；切換後自動選取該分類，並顯示符合的報告份數。
- 老師頁面不提供內層摘要文字編輯區、學生版預覽或討論問題區。老師與學生的全班摘要都沒有全班時間軸；只在個人報告顯示個人觀點變化時間軸。老師端已移除全班時間軸，學生端舊呈現仍需移除。
- 具有摘要編輯權限的助教仍有專用草稿修訂區，可編輯概述與觀點總結，儲存後交老師審閱；未儲存離頁會提醒。此權限不包含發布。

### 教師審閱與公開版本

- 老師確認摘要表述、統計及公開範圍後，勾選確認並標記該草稿版本審閱完成。
- **發布給學生**：只由老師操作，經確認後發布已審閱版本；學生於 P08 讀取此快照。
- 重新產生或修改草稿後，須重新審閱；新草稿不直接覆寫既有公開版本。
- **撤回發布**：老師確認後停止學生取得公開摘要，教學端資料仍保留；不是刪除活動。
- 公開內容不含姓名對照、個人報告入口、匿名代碼或其他學生的原話。

### 學生報告頁籤

- 清單顯示學生真名（註冊姓名）、匿名代碼、完成回合、日期、目前觀點與觀點 tag。
- **搜尋**：依姓名、匿名代碼、觀點或 tag 文字篩選。
- **tag 篩選**：可點群組、未形成明確觀點或清單上的 tag；顯示目前條件及符合份數。切換或清除 tag 會清空搜尋字詞；清除後回到完整列表。
- 新報告尚未納入目前摘要時顯示「待重新分群」；先前選取的分類已改變時顯示分類更新提示。
- 從摘要卡切入時直接套用該分類，不要求教師重新查找學生。
- **點擊學生報告**：開啟浮動視窗，顯示姓名、tag、匿名代碼、回合、版本、證據狀態與 P08 所列結構化內容。
- 報告保留個人觀點變化時間軸，可展開提問、學生回覆與前後總結；沒有另一個「支持理由・對話證據」獨立區塊。「最強理由」仍是報告欄位。
- 現行教學端報告視窗沒有跳至完整逐字對話的入口；不能承諾老師可瀏覽任一學生完整聊天室。
- 沒有報告、篩選無結果及載入失敗分別顯示狀態。助教報告權限遭撤銷後，關閉報告視窗並停止讀取。

使用者故事：作為老師，我希望知道各觀點由哪些學生提出，能回查報告並控制全班可見的摘要版本。
